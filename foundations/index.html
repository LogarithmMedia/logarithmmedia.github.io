// 06 · Motion and restraint

A calm signal..

The v2 homepage uses a single traveling dot-field swell. A demo may move; comprehension never depends on animation.

// one swell · ambient layer

Alive in the background. Quiet in the foreground.

Motion is paused when off-screen, manually paused, or when reduced motion is preferred. The diagram is decorative.

sin(x · 0.0085 − t · 1.25 + y · 0.0015)
Decorative motion enabled

// Behavior contract

More meaning. Less movement.

Original parameters are carried forward for documentation, not to reimplement the homepage in this page.

wave = sin(x*0.0085 − t*1.25 + y*0.0015)
displacement ≈ 5px
marquee loop = 38s
press feedback = 140ms
prefers-reduced-motion = static

Continuous marquees must offer a pause control in their future Blocks/Components implementation. Manual tabs and all content remain available without animation.

// 08 · Accessibility and release rules

Designed to be verified..

Target WCAG 2.2 AA. A visual specimen cannot replace browser, assistive-technology or real lead-form testing.

// design contract

Accessibility baseline

  • Normal text contrast ≥4.5:1, large ≥3:1.
  • Functional visual boundaries ≥3:1 where applicable.
  • Keyboard focus visible on light and dark.
  • Comfortable 44px touch targets where practical.
  • Semantic headings, accessible names and labels.
  • Reduced motion keeps all functionality.
  • No sideways page scrolling at tested widths.
  • Errors described with text, never color only.
