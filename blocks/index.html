// 04 — implementation rules

Predictable by design.

Semantic contract

Use a native button for actions and an anchor for destinations. Loading retains a textual label; disabled prevents activation. Never rely on icons alone without accessible names.

Hover sinks 1px; pressed sinks 3px. Focus stays visible. Reduced motion removes movement and spinner animation.

Review boundary

Theme mappings are draft candidates using the existing foundation palette. Dark text aliases are derived from the v2 dark surfaces. No production or lead capture integration. Browser and accessibility acceptance remain pending.
